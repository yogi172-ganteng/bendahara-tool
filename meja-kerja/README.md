# Meja Kerja Bendahara

Pratinjau UI/UX meja kerja. Ini bukan pengganti Apps Script di cabang `main`.

## Isi

- `src/components/meja-kerja.tsx` — halaman meja kerja
- `src/components/ui/primitives.tsx` — kartu, tombol, modal, tab
- `src/lib/keuangan.ts` — data contoh periode, tugas, transaksi, laporan
- `src/lib/utils.ts` — format rupiah
- `src/styles.css` — warna dan tipografi
- `src/routes/index.tsx` — route utama
- `public/favicon.svg` — ikon
